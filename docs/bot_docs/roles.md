# Роли и разграничение прав (Ранги)

В системе Selara пользователи разделены на несколько рангов (ролей), каждый из которых имеет свой уровень доступа к командам и функциям:

1. **Владелец (owner)**
   * Обладает абсолютными правами в чате.
   * Может выполнять любые действия, включая назначение других администраторов любого ранга.

2. **Совладелец (co_owner)**
   * Обладает почти всеми правами владельца.
   * Может использовать инструмент `set_rank` для назначения или изменения ролей других участников (за исключением понижения/изменения роли владельца).
   * Может выдавать и снимать любые дисциплинарные меры (варны, преды, баны, ресты).
   * Может управлять настройками чата и доступом к командам.

3. **Старший администратор (senior_admin)**
   * Обладает правами модерации.
   * Может выдавать и снимать любые дисциплинарные меры (варны, преды, баны, ресты).
   * **Ограничение:** не имеет доступа к инструменту `set_rank` (не может изменять роли пользователей) — это право только у co_owner и owner.

4. **Младший администратор (junior_admin)**
   * По умолчанию НЕ является модератором — это базовый ранг для тех, кому только нужно право на объявления.
   * **Ограничение:** по умолчанию не может выдавать/снимать преды, варны, баны и ресты (нет права `moderate_users`) и не имеет доступа к `set_rank`.
   * Владелец может выдать этому рангу дополнительные права через кастомную роль (`/roleperms`), если нужно сделать его модератором — по умолчанию это не так.

5. **Участник (participant)**
   * Обычный пользователь чата.
   * Не имеет прав на использование модерационных инструментов AI-ассистента.

Кроме этих системных рангов, в чате могут быть **кастомные роли** (созданные
через `/rolecreate` на основе одного из системных шаблонов, с произвольным
набором прав через `/roleperms`) — их название и фактические права могут
отличаться от системных умолчаний выше. Если встречаешь роль, которой нет в
этом списке, или у известной роли неожиданное поведение — она, скорее всего,
кастомная; проверяй её реальные права через `get_user_info`, а не полагайся
только на название ранга.

## Инструменты управления ролями
* **Изменить ранг/роль пользователя в боте:** инструмент `set_rank`
  * `target` (строка, обязательно): `@username`, образ или `user_id` пользователя.
  * `rank` (строка, обязательно): новая роль пользователя. Допустимые значения: `participant` | `junior_admin` | `senior_admin` | `co_owner` | `owner`.

*Правило применения наказаний:* В чате отсутствует автоматический иммунитет администраторов к наказаниям. Дисциплинарные меры (варны, преды, баны) могут быть применены к любому участнику (включая младших/старших админов), если это явно затребовано владельцем (owner) или старшим администратором.
