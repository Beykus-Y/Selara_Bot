# Selara AI: release checklist

Выполняется владельцем перед production-релизом серии PR13–PR17. Деплой не входит в
PR; пункты — проверки до и после.

## До релиза

- [ ] Сделан backup БД перед production-миграцией.
- [ ] `SELARA_AI_PRICE_STARS` установлен в production (положительное целое). Без
      него checkout выключен — это нормально для dev, но не для релиза.
- [ ] LLM-провайдер настроен: `LLM_ENABLED=true`, `LLM_API_KEY` задан. Проверить в
      Mini App Admin → AI → «Готовность Selara AI».
- [ ] Миграции `0072–0077+` применяются (`alembic upgrade head` на копии БД).
- [ ] Существующие бесплатные чаты сохраняют доступ к `?` / `??` и ручному
      `/summary` в пределах бесплатных квот.
- [ ] Owner exemption работает: чат, где `ADMIN_USER_ID` — администратор, показывает
      «Внутренний доступ» и не создаёт entitlement/payment rows.
- [ ] CI зелёный (`backend`, `frontend`) на актуальном HEAD, проведено независимое
      review этого HEAD.

## Бот и платежи

- [ ] `/premium` в личке: список чатов, терминология, счёт на корректную сумму.
- [ ] `/terms` и `/paysupport` отвечают.
- [ ] Тестовый платёж Stars (минимальная цена) либо безопасная production smoke
      процедура: оплатить в тестовом чате, убедиться в entitlement и в записи в
      истории платежей, затем при необходимости вернуть через `/stars_refund`
      (только для rejected) или оставить как реальную покупку.
- [ ] Повтор платежа не продлевает срок дважды; недоступная БД не теряет оплату.
- [ ] Алерты владельцу при retry/ошибке DB доходят.

## Функции Selara AI

- [ ] Ручной `/summary`: квота, сообщение об исчерпании, сброс по `BOT_TIMEZONE`.
- [ ] Scheduled Daily Summary: на free-чате не запускается; на paid-чате с
      включённым `daily_summary_enabled` запускается.
- [ ] `? / ??`: бесплатный лимит 10 в день; сообщение при исчерпании.
- [ ] Голосовые сообщения (STT) остаются бесплатными и вне access gate.

## Mini App

- [ ] Страница группы: блок «Selara AI» для free / paid / expired / owner internal;
      при сбое показывает «Статус временно не удалось проверить».
- [ ] Mini App Admin → AI: расходы, предупреждение о неизвестной стоимости,
      разбивки, Stars, активные подписки, история платежей, rejected/refund.
- [ ] Узкий экран (≈320–393 px): без горизонтальной прокрутки.

## После релиза

- [ ] Наблюдать «Готовность Selara AI» и operational alerts первые сутки.
- [ ] Проверить `pending` возвраты в Mini App Admin (требуют ручной сверки).
