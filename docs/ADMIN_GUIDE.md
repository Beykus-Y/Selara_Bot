# Selara — руководство для админов групп

Этот документ предназначен для администраторов Telegram‑групп, которые добавляют бота Selara в чат.

## 1. Коротко о боте
Selara — бот для статистики, игр, экономики и модерации. Он умеет:
- считать активность и строить топы
- вести репутацию и карму
- запускать мини‑игры
- давать экономику (ферма, клики, лотерея, рынок)
- модерировать (преды, варны, баны)
- работать с ролями внутри бота

## 2. Подготовка перед добавлением
Перед добавлением в группу проверьте:
- У вас есть права администратора в группе.
- Вы знаете точный `@username` бота (например, `@SelaraBot`).
- Если нужны текстовые команды без `/` и реакции на обычные сообщения (карма `+/-`, социальные действия), необходимо отключить privacy mode в BotFather.

### Отключение privacy mode (важно для текстовых команд)
1. Откройте BotFather.
2. Команда `/setprivacy`.
3. Выберите бота.
4. Установите `Disable`.

Без этого бот будет получать только команды и упоминания, и часть функций не будет работать.

## 3. Добавление бота в группу
1. В группе нажмите «Добавить участника».
2. Введите `@username` бота.
3. Добавьте бота в группу.
4. (Рекомендуется) сразу сделайте бота администратором.

## 4. Права администратора бота
Минимальные права для базовой работы:
- Отправка сообщений
- Отправка медиа

Для модерации боту нужны дополнительные права:
- Блокировка пользователей (Ban users / Restrict users)

Если бота не сделать администратором, команды модерации будут работать только «внутренне» (статистика будет обновляться), но фактический Telegram‑бан не применится.

## 5. Инициализация ролей бота
Внутри Selara есть собственные роли:
- `Участник`
- `Мл. админ`
- `Старший админ`
- `Совладелец`
- `Владелец`

Также можно создавать кастомные роли (например, `Видеомонтажер`) из шаблона и отдельно редактировать их права/ранг.

### Первый владелец
Если в чате ещё нет ролей, первый вызов явной role-команды (`/roles`, `/roleadd`, `/roleremove`, `/rolecreate`, `/roleperms` и т.д.) создаёт первого `Владельца` автоматически.

### Основные команды ролей
- `/roles` — список ролей
- `/roledefs` — список всех доступных ролей (system/custom) и прав
- `/roleadd "<role>" @user` — назначить роль
- `/roleremove @user` — снять роль
- `/roletemplates` — показать системные шаблоны ролей
- `/rolecreate "<название>" ["шаблон"] [ранг]` — создать кастомную роль
- `/rolesettitle "<роль>" "<новое название>"` — переименовать кастомную роль
- `/rolesetrank "<роль>" <ранг>` — изменить ранг кастомной роли
- `/roleperms "<роль>" +право -право ...` — редактировать права кастомной роли
- `/roledelete "<роль>"` — удалить кастомную роль

Пример:
- `/roleadd "Совладелец" @username`
- `/rolecreate "Видеомонтажер" "Мл. админ" 15`
- `/roleperms "Видеомонтажер" +announce -manage_games`
- `/roleremove @username`

Через ЛС-панель (`/start` -> группа -> `Роли`) можно делать то же самое текстовыми командами.

## 6. Настройки группы
Команды:
- `/settings` — показать текущие настройки
- `/setcfg <key> <value>` — изменить настройку (нужно право `manage_settings`)
- `/setrank "<команда>" "<роль>"` — установить минимальный ранг для команды
- `/ranks` — показать все настроенные ранги команд
- Текстом в группе: `установить "команда" ранг внутри бота роль`
- Текстом в ЛС-панели (`/start` -> группа -> `Ранги команд`) работают те же форматы.

Сброс к значениям по умолчанию (из env):
- `/setcfg <key> default`

Ниже перечень ключей и краткое описание. Точные текущие значения и дефолты смотрите в `/settings`.

- `top_limit_max` — максимальный размер топа
- `vote_daily_limit` — дневной лимит голосов кармы
- `leaderboard_hybrid_buttons_enabled` — показывать кнопки переключения топа (true/false)
- `leaderboard_hybrid_karma_weight` — вес кармы в гибридном топе (0..1)
- `leaderboard_hybrid_activity_weight` — вес активности в гибридном топе (0..1)
- `leaderboard_7d_days` — количество дней для топа 7d
- `leaderboard_week_start_weekday` — день старта недели для недельного топа (0=пн ... 6=вс)
- `leaderboard_week_start_hour` — час старта недели в UTC (0..23)

**Мафия**
- `mafia_night_seconds` — длительность ночи
- `mafia_day_seconds` — длительность дня
- `mafia_vote_seconds` — длительность голосования
- `mafia_reveal_eliminated_role` — показывать ли роль выбывшего (true/false)

**Текстовые команды и контент**
- `text_commands_enabled` — включить текстовые команды (true/false)
- `text_commands_locale` — язык текстовых команд (`ru` или `en`)
- `actions_18_enabled` — включить встроенные 18+ reply-действия, «дрочку» и 18+ темы для `Кто я` (true/false)
- `smart_triggers_enabled` — включить смарт-триггеры чата (`/settrigger` и т.д., см. раздел 9.1) (true/false)
- `custom_rp_enabled` — включить кастомные RP-шаблоны (`/rpadd` и т.д., см. раздел 9.1) (true/false)
- `iris_view` — формат отображения профилей/карточек (см. `/settings` для допустимых значений)

**Приветствие и прощание**
- `welcome_enabled` — приветствовать новых участников (true/false)
- `welcome_text` — текст приветствия (поддерживает `{user}`, `{chat}` и другие переменные из раздела 9.1)
- `welcome_button_text` — текст кнопки под приветствием (пусто — без кнопки)
- `welcome_button_url` — ссылка для кнопки приветствия
- `goodbye_enabled` — присылать сообщение при выходе участника (true/false)
- `goodbye_text` — текст прощания
- `welcome_cleanup_service_messages` — удалять служебное сообщение Telegram о входе участника (true/false)
- `cleanup_leave_service_messages` — удалять служебное сообщение Telegram о выходе участника (true/false)

**Капча и антирейд**
- `entry_captcha_enabled` — требовать капчу от новых участников при входе (true/false)
- `entry_captcha_timeout_seconds` — сколько секунд даётся на прохождение капчи
- `entry_captcha_kick_on_fail` — исключать участника при непрохождении капчи (true/false)
- `antiraid_enabled` — включить защиту от массового вступления ботов/спамеров (true/false)
- `antiraid_recent_window_minutes` — окно в минутах, за которое считается «массовое» вступление

Текстом в группе (нужно право `manage_settings`):
- `+антирейд` / `-антирейд` — включить/выключить антирейд без `/setcfg`.

**Модерация чата**
- `chat_write_locked` — временно заблокировать команды экономики/игр/отношений/соц-действий в чате (true/false)
- `save_message` — сохранять текст сообщений для последующего просмотра (true/false)

Текстом в группе (нужно право `manage_settings`):
- `-чат` / `+чат` — быстро заблокировать/разблокировать команды чата без `/setcfg`.

**Семья, образы, титулы**
- `family_tree_enabled` — включить семейное дерево (`/family` и связанные команды) (true/false)
- `persona_enabled` — включить образы (персонажи) участников (true/false)
- `persona_display_mode` — как показывать образ в профиле/сообщениях (допустимые значения см. в `/settings`)
- `titles_enabled` — включить покупаемые титулы (true/false)
- `title_price` — цена титула в монетах

**Крафт и аукционы**
- `craft_enabled` — включить крафт предметов (true/false)
- `auctions_enabled` — включить аукционы (true/false)
- `auction_duration_minutes` — длительность аукциона в минутах
- `auction_min_increment` — минимальный шаг ставки на аукционе

**Интересные факты**
- `interesting_facts_enabled` — периодически присылать в чат интересные факты (true/false)
- `interesting_facts_interval_minutes` — как часто присылать (в минутах)
- `interesting_facts_target_messages` — сколько сообщений в чате должно пройти перед следующим фактом
- `interesting_facts_sleep_cap_minutes` — не присылать факт, если чат неактивен дольше этого времени (в минутах)

**Экономика**
- `economy_enabled` — включить экономику (true/false)
- `economy_mode` — режим экономики (`global` или `local`)
- `economy_tap_cooldown_seconds` — кулдаун на `/tap`
- `economy_daily_base_reward` — базовая награда `/daily`
- `economy_daily_streak_cap` — максимум стрика `/daily`
- `economy_lottery_ticket_price` — цена билета лотереи
- `economy_lottery_paid_daily_limit` — лимит платных билетов в день
- `economy_transfer_daily_limit` — дневной лимит переводов
- `economy_transfer_tax_percent` — налог на переводы (0..100)
- `economy_market_fee_percent` — комиссия рынка (0..100)
- `economy_negative_event_chance_percent` — шанс негативного события (0..100)
- `economy_negative_event_loss_percent` — процент потерь при негативном событии (0..100)
- `cleanup_economy_commands` — удалять сообщения с экономическими командами после ответа бота (true/false)

**AI-ассистент**
- `llm_enabled` — включить AI-ассистента (`?`/`??`, см. раздел 13) для этого чата (true/false)
- `llm_context_threshold` — сколько сообщений накапливается в режиме `??` перед автоматическим сжатием истории

**Итоги дня (бета)**
- `daily_summary_enabled` — присылать ежедневную AI-сводку чата (требует включённый `save_message`) (true/false)
- `daily_summary_hour` — час отправки сводки по времени бота (0..23)
- `daily_summary_min_messages` — минимум сообщений за последние сутки, чтобы сводка вообще формировалась
- `daily_summary_style` — тон сводки: `neutral`, `lively` или `snarky`
- `daily_summary_include_voice` — учитывать расшифровки голосовых сообщений при формировании сводки (true/false)
- `daily_summary_include_video_notes` — учитывать расшифровки видео-кружков при формировании сводки (true/false)

**Итоги дня — команда**
- `/summary` — запросить итоги дня вручную (право `manage_settings`), независимо от
  того, включена ли `daily_summary_enabled`. Требует включённый `save_message` и
  достаточно сообщений за последние сутки (`daily_summary_min_messages`). Не больше
  одного ручного запроса в календарные сутки на чат.

## 7. Модерация
Команды модерации работают в группе и требуют право `moderate_users`.

Команды:
- `/pred` — выдать предупреждение
- `/warn` — выдать варн
- `/unwarn` — снять варн
- `/ban` — забанить
- `/unban` — разбанить
- `/modstat` — посмотреть статус предов/варнов/банов

Можно использовать reply‑команды без `/`:
- `пред`, `снять пред` (или `разпред`/`анпред`), `варн`, `снять варн` (или `разварн`/`анварн`),
  `бан`, `разбан` (или `анбан`), `повысить`, `понизить`.
- Работают и английские формы: `pred`, `warn`, `ban`, `unban`, `unwarn`.

Правило:
- `3 преда = 1 варн`
- `3 варна = 1 бан`

Рест (официальный отпуск от нормы активности — не мьют, не бан) и образы
(персонажи участников) — тоже прямые текстовые команды админа, не только
то, что умеет делать AI-ассистент (раздел 13):
- `выдать рест 7 @username` (или reply + `выдать рест 7`) — выдать рест на 7 дней.
- `забрать рест @username` (или reply) — снять рест раньше срока.
- `ресты` — список всех активных рестов в чате.
- `выдать образ @username "Дракон"` (или reply + `выдать образ "Дракон"`) — назначить образ.
- `снять образ @username` (или reply) — снять образ.
- `образы` — список всех образов в чате.

Если у бота нет права «Блокировать пользователей», Telegram‑бан не применится, но внутренний статус обновится.

## 8. Кастомные алиасы текстовых команд
Админ с правом `manage_settings` внутри бота может задать свои триггеры для текстовых команд в конкретной группе.

Команды:
- `/setalias "стандартный триггер" "новый алиас" [--force]` — добавить или переназначить алиас
- `/aliases` — показать текущий режим и список алиасов
- `/unalias "алиас"` — удалить алиас
- `/aliasmode aliases_if_exists|both|standard_only` — режим применения алиасов

Режимы:
- `both` — работают и стандартные, и кастомные триггеры
- `aliases_if_exists` — если у команды есть кастомный алиас, стандартный триггер этой команды не работает
- `standard_only` — работают только стандартные триггеры

Примеры:
- `/setalias "нейминг" "+ник"`
- `/setalias "кто я" "мой профиль"`
- `/setalias "нейминг" "+ник" --force`
- `/aliasmode aliases_if_exists`

Важно:
- Встроенные стандартные триггеры защищены от перехвата.
- `--force` нужен только для конфликта с уже существующим кастомным алиасом.

Команда:
- `объява "текст"` — пинг участников и 5 сообщений объявления (нужно право `announce` или подходящий ранг команды)

Участники могут отключать теги объявления:

- `рег` — включить теги

## 9.1. Смарт-триггеры и шаблонные переменные
Смарт-триггеры можно создавать как из Telegram, так и из web-панели группы.

Команды:
- `/settrigger "ключ" "ответ" [exact|contains|starts_with]`
- `/triggers` — список текущих смарт-триггеров
- `/deltrigger <id>` — удалить смарт-триггер
- `/triggervars` — показать все доступные `{переменные}`

Кастомные RP-действия используют тот же шаблонизатор:
- `/rpadd "триггер" "шаблон"`
- `/rps`
- `/rpdel "триггер"`

Полезные переменные:
- `{user}` / `{actor}` — отправитель как упоминание
- `{user_name}` — имя отправителя без ссылки
- `{reply_user}` / `{target}` — пользователь из reply
- `{reply_text}` — текст reply-сообщения
- `{chat}` — название чата
- `{text}` — текст текущего сообщения
- `{args}` — хвост после ключевой фразы
- `{date}`, `{time}`, `{datetime}`, `{weekday}` — дата и время по UTC

Примеры:
- `/settrigger "кто тут" "Сейчас тут {user}, чат: {chat}, время: {time}"`
- `/settrigger "привет" "Привет, {user_name}. Ты ответил(а) на: {reply_text}"`
- `/rpadd "куснуть" "{actor} кусает {target}. Комментарий: {args}"`

Важно:
- Для буквальных фигурных скобок используйте `{{` и `}}`.
- Reply-переменные работают только если исходное сообщение было отправлено reply.
- В web-панели полный список переменных доступен на странице группы и в `/app/docs/admin`.

## 10. Игры и ЛС
Некоторые игры требуют личных сообщений с ботом (роли, ответы, приватные карточки).

Рекомендуйте участникам:
- открыть чат с ботом и нажать `Start`
- разрешить боту писать в ЛС

Без этого бот не сможет отправить роли и приватные подсказки.

## 10.1. Гача (Genshin/HSR) — управление

Гача — отдельная мини-игра (два баннера: «генш» и «хср»), работающая через отдельный
gacha-сервис бота. Управляется не через `/settings`/`/setcfg`, а отдельными командами:

- `гача вкл` / `гача выкл` — текстом в группе, включает/выключает гачу в этом чате
  (нужно право `manage_settings`, либо `GACHA_ADMIN_USER_ID`/`ADMIN_USER_ID`). Можно
  указать длительность: `гача выкл 5м` / `2ч` / `1д` — тогда состояние вернётся
  автоматически.
- `гача админ обяз @username` / `гача админ необяз @username` (или reply вместо
  `@username`) — только для `GACHA_ADMIN_USER_ID`: делает подписку на служебный канал
  обязательной/необязательной для конкретного игрока.
- `гача скип генш`/`гача скип хср [@username]` — только для `GACHA_ADMIN_USER_ID`: сбрасывает
  кулдаун крутки. Без `@username`/reply сбрасывает себе.
- `/gachagive <code> @username` (или reply вместо `@username`) — только для
  `GACHA_ADMIN_USER_ID`: выдаёт конкретную карту игроку напрямую. `@username`/reply
  обязателен — без явной цели команда откажет, а не выдаст карту себе.

`GACHA_ADMIN_USER_ID` и `GACHA_ADMIN_TOKEN` — переменные окружения бота, не настройки чата.
`GACHA_ADMIN_USER_ID` также получает служебное уведомление в ЛС, когда фоновый
прогрев кэша анимаций круток завершается — это не только права на команды.

Каждая крутка сопровождается короткой анимацией. Она включена всем по умолчанию
и переключается лично каждым игроком (кнопка «🎬 Анимация» под `гача инфо`) —
это не настройка чата и не то, что может включить/выключить админ централизованно.

## 10.2. Веб-панель (Mini App и ПК-панель)

Кроме команд в чате, у Selara есть веб-панель — для тех, кому удобнее настраивать
группу через интерфейс, а не текстовыми командами. Действия там дают ровно те же
права, что и в чате: чтобы что-то менять, нужны те же права администратора бота
(`manage_settings`/`manage_command_access`/`manage_role_templates` — см. §5).

Два способа войти:
- **📱 Mini App** — кнопка в личном чате с ботом (после `/start`). Открывается прямо
  внутри Telegram, отдельный вход не нужен — Telegram сам подтверждает, кто вы.
  Это основной способ с телефона.
- **🖥 ПК-панель** — для входа с компьютера отправьте боту в ЛС команду `/login`: он
  пришлёт одноразовый код и ссылку на сайт. Введите код на сайте — откроется тот же
  кабинет, что и в Mini App. Код одноразовый и ограничен по времени (сколько именно —
  бот напишет прямо в сообщении с кодом); никому его не пересылайте.

Что внутри кабинета:
- **Список ваших групп** — куда добавлен бот и где у вас есть права (или откуда вы
  просто писали сообщения — это отдельный, ограниченный вид без прав администратора).
- **Карточка группы** — вкладки: обзор (текущие роли и индивидуальные ранги команд),
  достижения группы, настройки (все ключи из `/setcfg`/`/settings` в виде формы,
  без необходимости помнить точные названия), журнал действий модерации и текстовые
  алиасы, шаблоны триггеров для приветствия/объявлений (см. §9.1).
- **Игры** и **достижения аккаунта** — отдельные разделы вне привязки к одной группе.
- **Справка** — тот же раздел, что и `/app/docs/admin`, плюс короткая страница
  «Как начать» для новых участников, если им нужна помощь на минуту.

## 11. Проверка базовой работы
После добавления сделайте быстрый чек:
1. `/help` — бот отвечает
2. `/me` — строит профиль
3. `/game` — открывает меню игр
4. `/settings` — показывает настройки

## 12. Быстрые проблемы и решения
- Бот не реагирует на текстовые команды: включите `text_commands_enabled` и отключите privacy mode в BotFather.
- Команда `/ban` пишет, что бан не применён: дайте боту права на блокировку.
- Участник не получает роль в ЛС: пусть откроет диалог с ботом и нажмёт `Start`.
- Команды настроек/рангов не работают: убедитесь, что у вашей роли есть нужные права (`manage_settings` или `manage_command_access`).

## 13. AI-ассистент для модерации

В группе можно обратиться к AI-ассистенту прямо текстом — он отвечает на
вопросы про участников и статистику и может выполнить модерацию по вашей
просьбе.

### Как вызвать
- `? <запрос>` — разовый вопрос, без сохранения истории переписки.
- `?? <запрос>` — то же самое, но ассистент помнит предыдущие обращения в
  этом чате и учитывает их при ответе.

Примеры:
- `? покажи топ по активности`
- `? у Иван есть варны?`
- `?? выдай варн @username за спам`

### Кто может пользоваться
Нужна роль с правом `moderate_users` (по умолчанию — Старший админ и выше):
тогда ассистент отвечает на вопросы и выполняет модерацию по запросу.

Если хотите дать кому-то доступ только к вопросам — без права банить,
варнить и т.д. — создайте кастомную роль с правом `use_llm_readonly`:
`/rolecreate "<название>"`, затем `/roleperms "<название>" +use_llm_readonly`.
С этим правом ассистент отвечает на вопросы, но откажет в любом
модерационном действии — их по-прежнему выполняет только `moderate_users`.

### Что ассистент умеет
- Смотреть профиль/статистику участника, топы, журнал модерации.
- Выдавать и снимать пред/варн/бан/рест/образ.
- Менять роль пользователя внутри бота (в рамках вашего собственного ранга).
- Вести словарь терминов и сленга чата: искать, добавлять и удалять записи.
- Сказать точную текущую дату, время и день недели.

После модерационного действия ассистент присылает вам в ЛС короткую сводку
с кнопкой «Откатить» — если действие было ошибочным, его можно отменить в
один клик.

### Сброс контекста
Если переписка в режиме `??` пошла не туда или накопился нерелевантный
контекст — `?reset` очищает историю обращений в этом чате и начинает её
заново. Нужно то же право `moderate_users`.

### Ограничения
- Между обращениями к ассистенту в одном чате от одного администратора
  есть небольшая пауза — при слишком частых вызовах ассистент попросит
  подождать.
- Ассистент пока не видит экономику, гачу и семейные связи — только
  активность, роли, модерацию и словарь чата.
